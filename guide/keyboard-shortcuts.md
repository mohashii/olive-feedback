# Keyboard shortcuts

The same editing shortcuts work in the Mac app and in the VS Code extension. The Windows and Linux column applies to the VS Code extension.

## Editing

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Undo | `⌘Z` | `Ctrl+Z` |
| Redo | `⇧⌘Z` or `⌘Y` | `Ctrl+Shift+Z` or `Ctrl+Y` |
| Bold | `⌘B` | `Ctrl+B` |
| Italic | `⌘I` | `Ctrl+I` |
| Strikethrough | `⇧⌘S` | `Ctrl+Shift+S` |
| Inline code | `⌘E` | `Ctrl+E` |
| Link | `⌘K` | `Ctrl+K` |
| Inline math | `⇧⌘E` | `Ctrl+Shift+E` |
| Paste as plain text | `⇧⌘V` | `Ctrl+Shift+V` |
| Line break within a paragraph | `Shift+Enter` | `Shift+Enter` |
| Find | `⌘F` | `Ctrl+F` |
| Find next / previous | `⌘G` / `⇧⌘G` | `F3` / `Shift+F3` |
| Replace | `⌥⌘F` | `Ctrl+H` |

## Blocks

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Paragraph | `⌘⌥0` | `Ctrl+Alt+0` |
| Heading 1–5 | `⌘⌥1` – `⌘⌥5` | `Ctrl+Alt+1` – `Ctrl+Alt+5` |
| Numbered list | `⇧⌘7` | `Ctrl+Shift+7` |
| Bulleted list | `⇧⌘8` | `Ctrl+Shift+8` |
| Quote | `⇧⌘B` | `Ctrl+Shift+B` |
| Code block | `⌘⌥C` | `Ctrl+Alt+C` |
| Move block up / down | `⌥↑` / `⌥↓` | `Alt+↑` / `Alt+↓` |
| Open the block menu | `⌃↩` | `Ctrl+Enter` |
| Select the current block | `Esc` | `Esc` |
| Extend the block selection | `Shift+↑` / `Shift+↓` | `Shift+↑` / `Shift+↓` |
| Indent / outdent a list item | `Tab` / `Shift+Tab` | `Tab` / `Shift+Tab` |

Pressing the list, quote or code-block shortcut again on a block that is already that kind turns it back into text. The heading shortcuts do not toggle back that way — use **Paragraph**. With the caret in a list item, the list shortcuts change that one item rather than the whole list.

Heading 6 has no shortcut; type `###### ` at the start of a line. Table rows and columns have no shortcut either; move them from the table's menu (see [Tables](tables-callouts-diagrams.md#tables)). With several blocks selected, the move shortcuts move all of them.

## Control-key navigation on macOS

Olive keeps the Emacs-style text navigation that macOS provides everywhere, including inside math fields, tables, toggles and menus.

| Keys | Movement |
| --- | --- |
| `Ctrl+B` / `Ctrl+F` | One character left / right |
| `Ctrl+P` / `Ctrl+N` | One line or menu item up / down |
| `Ctrl+A` / `Ctrl+E` | Start / end of the line or menu |
| `Ctrl+G` | Cancel an open menu, popup or drag |

On Windows and Linux these key combinations are left to VS Code and the operating system.

## In the Mac app

| Action | Keys |
| --- | --- |
| Save now | `⌘S` |
| Back / forward | `⌘[` / `⌘]` |
| Today's daily note | `⌥⌘N` |
| New window | `⌘N` |
| Settings | `⌘,` |

The text-formatting shortcuts are also listed in the **Format** menu.

## In VS Code

Olive's editing commands appear under **Olive** in VS Code's Keyboard Shortcuts editor (`⌘K ⌘S`, or `Ctrl+K Ctrl+S`). You can search for them there, change their keys, or see when another extension uses the same keys.
